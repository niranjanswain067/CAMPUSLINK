## 1. Design Principles
1. **Role-first navigation** — each role sees only what it needs.
2. **Explain everything** — every score has a "Why?" drawer.
3. **Action-oriented** — every alert has a next-step button.
4. **Glanceable dashboards** — KPIs on top, detail below.
5. **Accessible & responsive** — mobile-friendly, keyboard navigable, AA contrast.

### 5.3 Readiness Page
- Gauge (0–100) with band label.
- **Breakdown bars:** Academics, Technical skills, Aptitude, Mock interview, Soft skills, Projects/Certs — each with weight and contribution.
- **Skill-gap panel:** choose target role → table (skill, required level, current level, gap, suggested resource).
- **Prep plan** generated by AI with checklist and "gamified" progress badges/streaks.

### 5.4 Drive Detail (Student view)
- Company, role, CTC, dates, eligibility checklist (✔ CGPA, ✔ Branch, ✖ Backlogs).
- **Fit card:** score ring + band + "Why this score?" accordion (matched skills, missing skills, interview benchmark).
- Apply button (disabled with reason if ineligible).

### 5.5 TPO Command Dashboard
```
KPI row:  Registered | Placement-ready | Active drives | Offers made | Accepted | Pending
Row 2:    [Branch-wise conversion bar] [Skill-wise conversion heatmap]
Row 3:    [Avg / Highest package trend line] [Offer funnel]
Row 4:    [At-risk students table + Escalate] [Recruiter pipeline kanban-lite]
Row 5:    [Documentation & joining status stacked bar] [Upcoming drives + conflicts badge]
Filters:  Campus · Branch · Year · Date range
```

### 5.6 Matching Page (TPO/Recruiter)
| Rank | Student | Branch | CGPA | Fit | Band | Decision | Why |
|---|---|---|---|---|---|---|---|
| 1 | A. Rao | CSE | 8.7 | 91 | Highly Employable | Shortlisted | ▸ |

- Row expand → factor bars + narrative:
  *"Below Threshold: CGPA meets criteria, but skill gap in cloud technologies and mock-interview score below benchmark."*
- Controls: threshold slider (live re-rank), "Auto-shortlist", manual override (reason required), export CSV.

### 5.7 Scheduler
- Calendar (week/day/resource view: venues & panels as rows).
- Drag-and-drop rounds; conflicts shown as red badges with popover.
- **Conflict panel:** list of conflicts → "Suggest fix" → top 3 alternatives → Apply.
- Publish disabled until blocking conflicts = 0.

### 5.8 Offers & Documents
- Pipeline columns: Issued · Accepted · Deferred · Declined · Withdrawn · Joined.
- Offer drawer: CTC, role, joining date, document checklist with status chips and "Send reminder".
- Offer-letter upload shows SHA-256 verification badge.

### 5.9 At-Risk Page
- Table sorted by risk probability; top contributing factors as chips; actions: Assign mentor · Create plan · Send nudge.

### 5.10 Assistant
- Chat UI with suggested prompts ("Am I eligible for TCS?", "What should I improve?"), mock-interview mode with question → answer box → feedback card (score for relevance, structure, communication).

### 5.11 Notifications
- Bell dropdown (latest 10, unread badge) + full page with filters; TPO template editor and delivery log.

## 6. UX States
Every data view defines: **loading** (skeletons), **empty** (illustration + CTA), **error** (retry), **forbidden** (role message), **AI fallback** (subtle "AI unavailable — showing standard explanation" banner).

## 7. Interaction Rules
- Forms validate inline (Zod); destructive actions require confirm dialog.
- Optimistic UI for notification read/shortlist toggles.
- Toasts for success/failure; long AI tasks show progress and can run in background.
- Tables: server-side pagination, sort, filter, saved views.

## 8. Responsive Behaviour
| Breakpoint | Layout |
|---|---|
| < 640 px | Bottom nav, single column cards, tables → card lists |
| 640–1024 px | Collapsible sidebar, 2-column grid |
| > 1024 px | Fixed sidebar, 3–4 column dashboards |

## 9. Accessibility
Semantic HTML, ARIA labels on charts (with data table alternative), focus rings, colour never the sole indicator (icons + text with band colours), reduced-motion support.
